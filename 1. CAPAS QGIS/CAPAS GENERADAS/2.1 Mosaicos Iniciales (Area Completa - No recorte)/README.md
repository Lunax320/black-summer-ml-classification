# 2.1 Mosaicos Iniciales

Mosaicos generados a partir de la unión de las teselas T56HKH y T56HKJ para cada banda espectral, antes del recorte al ROI.

🔗 **[Descargar Mosaicos Iniciales](https://drive.google.com/drive/folders/1RynhXUKhY1j1qomiCvt6sxjumVnpFvv0?usp=sharing)**

**Contenido:**

- Mosaicos por banda (B01, B02, B03, B04, B05, B06, B07, B08, B11, B12).
- Proyecciones: ESPG 32756 y ESPG 7856.
- Área completa del parque (sin recorte).

**Procesamiento:** Herramienta Combinar en QGIS (`Ráster → Miscelánea → Combinar`).
